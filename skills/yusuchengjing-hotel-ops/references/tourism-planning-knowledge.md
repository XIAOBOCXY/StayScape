# 文旅策划知识库使用说明

data/tourism_context.json 收录宏观背景、杭州资源语境、案例观察、项目基础信息清单和回答工作流；data/tourism_knowledge.json 是杭州公共 POI 参考条目。

## 来源和适用边界

- REFERENCE_ONLY 是策划分析资料，不代表当前开放、票价、交通或合作状态。
- RUNTIME_SOURCE_ONLY 的房价、库存、日期和服务只能读取 StayScape 当前交易数据。
- VERIFY_REQUIRED 的 POI 先核验来源与更新时间再提供具体运营事实。知识库没有地图路由接口，因此不得给出酒店到 POI 的精确分钟数。
- 适配度评分是编辑整理的相对参考，不是实测、用户统计或适龄/安全认证。
- 案例总结中的可复用点属于分析归纳；不得把案例的客流、收入、投资和盈利模式外推为项目预测。
- 公开统计必须保留来源日期和口径；来源时间较旧时按历史背景使用。

## 规划流程

识别任务 → 合并最近对话与已确认偏好 → 校验硬约束 → 检索当前可售产品及来源 → 说明证据和取舍 → 只追问关键缺口 → 输出可执行方案。无法核验时明确待核验，绝不补造事实。

知识维护时，每条记录应包括来源标题、发布方、链接、发布日期/核验日期和状态。政策、票价、营业时间、交通及库存发生变化时优先复核官方或系统权威来源。
