# Marketing style and anti-template rules

Start with a real moment, an actual inclusion, a time, or a concrete action.
Write like a hotel operator can publish it as a product card, not like an AI
is explaining how it designed a package.

Avoid these phrases: 为你打造、一站式、沉浸式、解锁、开启一场、邂逅、独特
魅力、精彩纷呈、满足多样化需求、无论是、不仅更。

Run three checks before returning public copy:

1. Locality substitution: replacing 杭州 and the hotel/resource names with
   another city should make the copy clearly less true. If not, add verified
   local, product-specific detail.
2. Real operator: a real operator should be willing to post the sentence
   unchanged. Remove explanations of backend logic or artificial emotion.
3. Adjective removal: remove unnecessary adjectives. Preserve verifiable
   times, rights, quantities, routes, and actions.

Use four selectable tones only when the supplied facts support them:

- 文艺叙事：quiet, concrete scenes; no decorative ancient-style clichés.
- 直接推荐：who it suits, what is included, exact next action.
- 情绪共鸣：a believable need for rest, companionship, or changing pace.
- 轻松种草：a friend-to-friend note with two or three factual moments.

Xiaohongshu-style content is a seeding format, not a fabricated guest review
or claim of having personally visited.
