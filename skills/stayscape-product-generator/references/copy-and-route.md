# 中文文案与路线规范（文旅产品写法）

这份文件定义产品候选里「中文怎么说」和「一天怎么排」。运营端与游客端都直接渲染这些字段，命名和路线不用套话，要能被当成行程单执行。

## 一、命名

| 字段 | 长度 | 结构 | 示例 |
| --- | --- | --- | --- |
| `product_name` | 8–14 字 | 场景/情绪 + 核心体验 | 雨夜宋韵 · 双人城市漫游 |
| `theme` | 4–10 字 | 主题方向，供运营分类 | 演出夜游 / 亲子手作 / 城市运动 |
| `marketing_title` | ≤ 20 字 | 游客视角，可有画面感 | 下雨也不扫兴：看一场宋韵夜演 |

命名检查：

- 不出现「套餐、组合、方案、精选、尊享」；
- 不堆三个以上名词（形容词 + 名词 + 名词 ×3）；
- 不写没在快照里出现的地点或设施。

## 二、一日路线模板

雨天（`weather` 含 RAIN）：

```
15:00 抵达酒店寄存行李（前台）
16:00–17:30 室内体验（合作资源 A，同一城区）
18:00–19:30 晚餐（酒店权益或附近餐厅，非套餐项要标注）
19:00–20:30 室内演出/夜游（合作资源 B，固定场次）
20:45 返回酒店
```

晴天：

```
09:30–11:30 户外体验（合作资源 A，上午光线与人流更好）
12:00–13:00 午餐与转场（预留 30–45 分钟）
14:00–15:00 办理入住或寄存
15:30–17:30 户外或半室内体验（合作资源 B）
18:00 起 晚间体验或自由时间
```

硬性要求：

- 一天最多 3 个正式体验，且至少一段自由时间；
- 跨区转场留 30–45 分钟，写「机动」而不是承诺具体车程；
- 有雨时以室内为主，户外只作可替换安排；
- 高强度体验之后接轻体验，不连续两项高强度；
- 每条行程都要有「时间 + 地点/资源名 + 做什么 + 大约多久」。

## 三、文案三段式

1. **场景钩子**（1 句）：什么天气、什么时候、去哪里、做什么。
   - 「下雨的傍晚 18:00 走到仁和路，用一桌杭帮菜把杭州的鲜和甜吃明白。」
2. **一天怎么过**（2–3 句）：按时间顺序写清住宿、正式体验、留白。
3. **适合谁 + 提示**（1–2 句）：同行人数、年龄限制、雨天影响、需要预约的部分。

`marketing_content` 120–220 字，三段齐全；`recommendation_reason` 60–120 字，必须解释路线逻辑（顺序、转场、天气、客群）。

## 四、禁用词与替换

| 禁用 | 替换写法 |
| --- | --- |
| 不容错过 / 必打卡 | 说清具体体验，例如「19:00 的宋韵演出，室内场次」 |
| 顶级 / 尊享 / 高端 | 写事实，例如「城市景观房，可住 2 人」 |
| 以官方公告为准 / 请先核验 | 直接写文旅库里的开放时间与预约要求；没有就不写 |
| FAMILY / COUPLE / RAIN / HARD_MAX | 亲子家庭 / 两人同行 / 有雨 / 预算上限 |
